# Prince Silver & Gold website
Static site (HTML, CSS, JS). No build step.

## Edit
- Phone, address, hours: index.html (Visit section)
- WhatsApp number and products: top of script.js
- Colours: variables at top of style.css

## Deploy
- Cloudflare Pages: connect the GitHub repo, build command empty, output directory `/`.
- GitHub Pages: Settings > Pages > deploy from main branch, root folder.
